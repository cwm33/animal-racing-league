# The illustrated Animal Racing League

36 individual full-body characters generated with the built-in image-generation capability, using the cheetah as the visual style reference. Characters face right, with transparent backgrounds and consistent warm, softly shaded 3D treatment. No hand-drawn SVG animal substitutes or generic animal icons are used.

The PNG links below open the original source artwork at full resolution. The two preview columns show the runtime illustration at actual 64px and 32px CSS sizes. Transparent padding is normalized for consistent framing and foot placement; originals remain untouched.

## Rebuilding and reviewing

Run `npm run assets:build`, `npm run assets:check`, and `npm run assets:review` from the repository root. The review command refreshes the committed collection preview and creates a complete small-size contact sheet and six larger detail sheets in the ignored `test-results/animal-art/` directory. The integrity checker validates PNG/WebP decoding, dimensions, alpha transparency, full roster coverage, and uncropped character bounds.

`art-direction.json` records the shared art direction and the anatomical brief for each species. `manifest.json` records original hashes, dimensions, alpha coverage, framing bounds, and byte sizes. The original elephant framing was rejected for touching an image edge and regenerated with additional transparent space around its trunk and tail.

These illustrations are playful representations, not anatomical reference plates. The racing database, animal statistics, and physics are unchanged by the artwork.

All 36 source PNGs were reviewed at full size, and all runtime illustrations were reviewed at 64 px and 32 px on a checkerboard. The 36 originals and 108 WebP derivatives pass decoding, alpha, framing, and source-hash checks. The combined runtime WebP collection is 1.48 MB; the original PNG collection is 39.41 MB and is not published in the app.
